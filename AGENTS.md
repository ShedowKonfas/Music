# AGENTS.md — Music
## Назначение
Консольный поиск треков SoundCloud через `soundcloud-v2`: запрос с клавиатуры, первые 5 результатов.
## Карта файлов
- `main.py` — `search_music(query)` и точка входа с `input()`.
- `requirements.txt` — только `soundcloud-v2`.
- `start.cmd` — запуск через `venv\Scripts\python.exe` с паузой.
- `.env` — пустая заготовка, кодом не читается.
- `README.md`, `AGENTS.md` — документация.
## Запуск и тесты
```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.cmd
```
Тестов нет; без запроса не добавляем. Проверка вручную: запрос → до 5 ссылок.
## Соглашения
- Вывод и сообщения об ошибках — на русском.
- Число результатов задаётся срезом `tracks[:5]`; менять только по просьбе.
- Клиент создаётся как `SoundCloud()` — без ключей в репозитории.
## Подводные камни
- Нужен интернет: `client_id` получается с сайта SoundCloud при запуске.
- `start.cmd` требует venv; иначе используйте `python main.py`.
- Ошибки поиска только печатаются, exit-код остаётся 0.
